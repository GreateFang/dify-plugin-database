# VexDB Dify 插件

为 **Dify 应用** 提供 **VexDB 向量数据库** 的一站式集成能力，覆盖数据库浏览、表管理、数据写入以及向量相似度检索，适合用于 RAG、语义搜索、Embedding 存储与检索等场景。

---

## 开源说明

本仓库提供 **VexDB Dify 插件** 的完整实现，适合：

* 希望在本地 / 私有环境中部署 Dify + VexDB 的用户
* 希望基于现有能力进行二次开发的开发者
* 希望将Vexdb向量数据库能力接入 Agent / Workflow 的团队


---

## 插件能力一览

| 能力    | 说明                      |
| ----- | ----------------------- |
| 数据库发现 | 列出 VexDB 实例中的所有数据库      |
| 表管理   | 列出 schema 下表，支持仅返回向量表   |
| 表结构感知 | 获取字段、类型、索引等元信息          |
| 数据写入  | 插入单行数据，支持 `floatvector` |
| 向量检索  | TopK 相似度搜索，支持多种距离类型     |

---

## 设计理念

* **弱假设**：不强依赖具体表结构，适合多业务场景
* **即插即用**：授权一次即可使用，必要时支持 `db_uri` 覆盖

---

## 安全与连接说明

* 数据库连接信息通过 Dify 的 **Secret Input** 管理
* 不在 Tool 返回中泄露任何敏感连接信息
* 支持通过 `db_uri` 临时指定连接，便于多库场景或调试
